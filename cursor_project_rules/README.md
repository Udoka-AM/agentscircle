# Agent Circle — Knowledge Base

Marketplace landing page for AI trading agents on Solana.
Repo: https://github.com/el-uno/agentscircle
Live: https://agentscircle.vercel.app

## Product

Anyone can rent a proven AI trading agent for prediction markets; builders get paid, ranked, and funded for stronger agents.

## Stack

Vite + React 18 + TypeScript. Single-page marketing site in `src/App.tsx` + `src/styles.css`. Lucide icons. Waitlist is frontend-only (local confirmation). Deploy via Vite `dist/` (Vercel / Railway / static).
